Work

LLVMIRToLC3Pass is an out-of-tree LLVM pass, written in C++, that lowers a subset of LLVM IR generated from C to LC-3 assembly: a 16-bit ISA with eight registers.

It supports add, and, shl, mul, alloca, store, br, load, icmp, phi, select, call, udiv, urem, lshr and switch. R6 is the stack pointer, R5 the frame pointer, R7 holds the return address. Every virtual register gets a stack slot, unsigned values are treated as signed, and there is no floating-point support.
