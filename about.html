Work

LLVMIRToLC3Pass — an out-of-tree LLVM pass, written in C++, that lowers LLVM IR generated from C down to LC-3 assembly: a 16-bit ISA with eight registers.

Four of those registers are pinned by the calling convention (globals base, frame pointer, stack pointer, return address), which leaves three for computation — so spilling is not an afterthought, it is the design. The return-address register doubles as the phi predecessor selector, which removes the need for edge splitting; and the six-bit immediate offset of LDR/STR caps a function at 32 locals, a limit that propagated backwards into the frame layout and then into the calling convention itself.

It covers phi, select, switch, getelementptr, variadic calls, and a small libc (printf, scanf, sprintf, sscanf). It is tested by 35 cases in three tiers; 16 of them assemble the generated code and run it on an LC-3 simulator, comparing stdout against expected output.
